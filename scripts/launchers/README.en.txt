CODEX DASHBOARD

Open CodexDashboard.exe or Avvia-CodexDashboard.vbs in this folder.
Settings: right-click the widget or use the tray icon menu.
You can also open Impostazioni-CodexDashboard.vbs.
Select English under Language, then Apply or Save.

Settings include size, idle opacity, always on top, position, automatic
startup, refresh interval, separate quota thresholds, notifications and language.
Apply saves without closing; Save applies and closes.
Cancel discards only changes that have not yet been applied.
Available/used quota display also applies to the updated plugin.
Choose manual closing or closing when Codex closes.
With Codex startup and closing enabled, the app exits completely when Codex
closes. A Windows task checks every 10 seconds and starts it when Codex opens.

Quota history and about/diagnostics are in the widget and tray menus.
Select a key in Stream Deck to override language, quota mode and threshold.

In the project folder, the installable plugin is in dist/streamdeck,
the logo kit in dist/branding and the complete bilingual installer in dist/installer.
Sources: src. Documentation: README.en.md and docs/*.en.md.
Previews and test results: build.

Requires Windows 10/11 x64, .NET Framework 4.8 and Codex signed in with ChatGPT.
The app uses your Codex sign-in, sends no prompts and needs no API keys.
Stream Deck 6.6 or later is required for the plugin.
