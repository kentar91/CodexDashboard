# Archivio storico

`prototypes` conserva le prime versioni PowerShell e i layout provati prima del programma Windows nativo. I file sono mantenuti come riferimento: possono contenere nomi o percorsi precedenti e non vengono usati dalla compilazione o dall'avvio attuale.

Il programma corrente è in `src`, il prodotto pronto all'uso in `dist/app`. L'avvio automatico si gestisce dal configuratore del programma, non dagli script storici.
